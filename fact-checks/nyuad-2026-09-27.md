## Bottom line

- **Zero hallucinations found.** Every specific number that could be checked — tuition, all
  three application deadlines + decision dates, degree type, scholarship coverage, testing
  policy — matched the official source **exactly**. The data-collection discipline held.
- **The data errs toward honesty, not invention:** it explicitly declines to publish
  grade thresholds NYUAD doesn't publish, and refuses to fabricate unpublished 2027-2028
  deadlines. This is the correct behavior.
- **CORRECTION (self-audit):** An earlier version of this report claimed the cost profile
  was "tuition only / incomplete." That was WRONG — an extraction-script error (queried
  non-existent field names, missed the populated `mandatory_fees_breakdown` /
  `estimated_living_costs_annual`). The full COA is present and sums to NYU's exact
  published $90,328. No write was made. Lesson: verify the actual record state before
  concluding a gap.
- **Adapter nuance (not a data problem):** NYUAD bills housing + food (guaranteed on-campus
  housing), so they sit in `mandatory_fees_breakdown`, while `estimated_living_costs_annual`
  is only $5,914 (transport + personal). A naive UI reading `estimated_living_costs_annual`
  as "living costs" would UNDER-state them. The adapter must present the billed-vs-estimated
  split correctly.
- **One item to resolve at go-live:**
  1. **Scholarship eligibility conflict:** genuine disagreement between NYUAD's own pages
     ("Emirati mothers" vs "mother or father"). Must be surfaced as a conflict with both
     sources shown, never resolved by guessing. Record is correctly at HUMAN_REVIEW.
- **One low-risk unverified item:** IELTS/Duolingo specific benchmark numbers (TOEFL 100
  confirmed). Presented as soft "competitive benchmarks", so low exposure.
